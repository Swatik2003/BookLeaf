# BookLeaf Project Write-Up

## Project Approach

The primary goal of this project was to build a clean and scalable MERN stack application focused on author support workflows. I prioritized creating a stable full-stack application with a good user experience and maintainable backend structure.

The application was developed using React.js for the frontend and Node.js, Express.js, and MongoDB Atlas for the backend and database.

## Key Priorities

During development, my main priorities were:

* User authentication using JWT
* Author dashboard workflow
* Book management system
* Ticket creation and tracking
* Responsive and professional UI
* Proper API structure
* Scalable backend folder organization

I focused on ensuring that all core workflows were functional and connected properly between frontend, backend, and database.

## Architecture Decisions

The backend follows a modular structure using:

* Routes
* Controllers
* Middleware
* Models

This separation makes the project easier to maintain and extend in the future.

MongoDB Atlas was used as the cloud database solution for scalability and persistent storage.

The frontend communicates with backend APIs using Axios, and JWT authentication was implemented for protected routes and session handling.

## Trade-Offs

Due to the assignment timeline, I prioritized:

* Core product functionality
* Stable API integration
* Database connectivity
* Deployment setup
* Clean UI implementation

instead of adding advanced production-level features.

Some advanced features such as:

* Real-time notifications
* Advanced analytics
* File uploads
* Role-based permissions

were intentionally left for future improvements.

## Future Improvements

If given more time, I would improve the project by adding:

* Better admin analytics dashboard
* Real-time ticket updates
* Role-based access control
* File upload support
* Improved ticket filtering and search
* Better API testing coverage
* Dockerized deployment setup

## Conclusion

This project helped me strengthen my understanding of full-stack MERN architecture, authentication systems, REST APIs, MongoDB integration, deployment workflows, and scalable project organization.

My main focus throughout development was building a maintainable and functional application with clean architecture and a professional user experience.
